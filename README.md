# ModeloPrototipo

Proyecto Python para deteccion de manos con multiples modelos y exportacion optimizada.

## Inicio rapido

1. Crear un entorno virtual e instalar dependencias.
2. Preparar el dataset en formato YOLO en `data/processed/`.
3. Entrenar con `scripts/train_yolo.py`.
4. Exportar con `scripts/export.py`.
